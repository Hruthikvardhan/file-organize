----------------------------------------------------------------
SCREEN 1 - PROJECT STRUCTURE (modules)
----------------------------------------------------------------

file_organizer/
  |
  +-- organizer.py   MAIN: argparse + FileOrganizer class
  |                  (plan, preview, organize, undo, duplicates,
  |                   scheduling)
  +-- scanner.py     FileScanner  (find files, info, duplicates)
  +-- mover.py       FileMover    (move, rename, rollback)
  +-- reporter.py    ReportGenerator (stats + txt/json export)
  +-- config.py      Config       (loads config.json)
  +-- logger.py      setup_logging (organizer.log, errors.log)
  +-- utils.py       helpers (sizes, md5, hidden files, colours)
  +-- config.json    categories + settings (user editable)
  +-- requirements.txt
  +-- README.md

Data kept outside the project (in the user's home folder):

  ~/.file_organizer/
      logs/        organizer.log   errors.log   (7 days kept)
      operations/  ops_<date>_<time>.json      (one per run)
      reports/     report_<date>_<time>.txt / .json

SCREEN 3 - PROGRAM FLOW
----------------------------------------------------------------

   python organizer.py <options>
              |
              v
     +------------------+
     | Parse arguments  |---- bad input ----> usage error (exit 2)
     +------------------+
              |
              v
     +------------------+
     | Load config.json |---- corrupt -----> use defaults
     | Start logging    |
     +------------------+
              |
     +--------+---------+----------------+----------------+
     |                  |                |                |
  --undo          --duplicates      --schedule X     (normal run)
     |                  |                |                |
     v                  v                |                v
 find newest       scan + MD5            |         scan folder
 operation log     group files           |         build plan
     |                  |                |                |
 ask Y/N          choose keep           loop:       --preview ?
     |            newest / oldest       run job            |
 move files             |               every X h     show plan
 back                ask Y/N               |          ask Y/N
     |                  |                 |                |
     +---------+--------+-----------------+----------------+
                         |
                         v
                move files / delete files
                save operation log (JSON)
                         |
                         v
                  print report  (+ export if --report)

================================================================
PAPER DRAWING TIPS
================================================================

When drawing on paper:

1. Use a ruler for the boxes
2. Draw the flow chart (Screen 3) first - it explains the tool
3. Draw the class diagram (Screen 2) second
4. Use different pen colours:
   - Black pen : boxes and text
   - Green pen : success messages
   - Red pen   : errors
   - Yellow    : warnings
   - Pencil    : notes and annotations
5. Use these symbols consistently:
   [  ] = option / button
   {  } = text the user types
   ->   = a file being moved
   <-   = annotation arrow
