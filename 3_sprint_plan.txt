TASK-001  Create project folder and virtual environment  [P1] [x]
  - mkdir file_organizer && cd file_organizer
  - python -m venv venv  (then activate it)
  - Verify: python --version shows 3.10 or newer
  Estimated time: 10 min

TASK-002  Install packages + requirements.txt            [P1] [x]
  - pip install schedule colorama tqdm
  - requirements.txt contains:
      schedule>=1.2.0
      colorama>=0.4.6
      tqdm>=4.66.0
  Estimated time: 10 min

TASK-003  Create config.json                             [P1] [x]
  - categories: Images, Videos, Audio, Documents, Code,
    Archives, Executables (everything else = Others)
  - exclude_folders: node_modules, .git, __pycache__
  - skip_extensions: crdownload, part, tmp, download, partial
  - size_limits_mb: small 1, large 100
  - log_retention_days: 7, default_mode: type
  Estimated time: 15 min

TASK-004  Create config.py (class Config)                [P1] [x]
  - Load config.json; create it with defaults if missing
  - Corrupt JSON -> fall back to defaults (log the error)
  - get_category(extension) with a fast lookup table
  - add_category(), add_exclude(), save()
  - Folders for logs / operation logs / reports in ~/.file_organizer
  Estimated time: 40 min

TASK-005  Create logger.py                               [P1] [x]
  - organizer.log (INFO and above) + errors.log (ERROR only)
  - Timestamp, level, module name, message
  - TimedRotatingFileHandler: rotate at midnight, keep 7 days
  - If the log folder cannot be created, never crash
  Estimated time: 30 min

TASK-006  Create utils.py                                [P1] [x]
  - format_size(bytes) -> "1.5 MB"
  - month_name(date) -> English month name
  - md5_hash(path) -> read in 1 MB chunks
  - is_hidden(path), is_system_file(path)
    (dot-files, Windows Hidden/System attributes, Thumbs.db ...)
  - confirm(prompt) -> yes/no question, default No
  - print_info / success / warning / error / header (colorama)
  Estimated time: 40 min

SPRINT 1 DONE WHEN:

  [x] config.json loads and "jpg" maps to Images
  [x] Corrupt config.json does not crash the tool
  [x] Log files appear in ~/.file_organizer/logs/

SPRINT 2 - SCANNER + MOVER (THE CORE ENGINE)
Duration : Day 3-4
Goal     : Find files and move them safely
================================================================

TASK-007  Create FileInfo + FileScanner.scan_directory   [P1] [x]
  - FileInfo dataclass: path, name, extension, size,
    modified, category
  - scan_directory(path, recursive, skip_dirs)
  - Errors: folder not found, path is a file, unreadable folder
  Estimated time: 45 min

TASK-008  get_file_info + get_file_type                  [P1] [x]
  - get_file_info(path) -> name, extension, size, modified date
  - get_file_type(extension) -> category name
  Estimated time: 20 min

TASK-009  Skip rules in the scanner                      [P1] [x]
  - Skip hidden files, system files, symlinks
  - Skip unfinished downloads (.crdownload, .part ...)
  - Skip excluded folders (node_modules ...)
  Estimated time: 25 min

TASK-010  FileScanner.find_duplicates                    [P1] [x]
  - Group files by size first (unique size = not a duplicate)
  - MD5 hash only the same-size files (tqdm progress bar)
  - Return {hash: [files]} for groups of 2 or more
  - Ignore empty files
  Estimated time: 35 min

TASK-011  FileMover: folders + rename_if_duplicate       [P1] [x]
  - create_folder_if_not_exists(path)
  - rename_if_duplicate(dest): photo.jpg -> photo_1.jpg -> _2
  Estimated time: 20 min

TASK-012  FileMover.move_file with error handling        [P1] [x]
  - Operation dataclass (src, dest, timestamp)
  - PermissionError -> "Permission denied" / "File in use"
  - ENOSPC -> DiskFullError (stop the run, clean partial file)
  - Missing source file -> FileMoveError
  Estimated time: 40 min

TASK-013  FileMover.rollback                             [P1] [x]
  - Reverse operations newest first
  - Never overwrite: use rename_if_duplicate on restore
  - Remove folders that become empty (never the destination root)
  - Return (restored_count, failures)
  Estimated time: 40 min

TASK-014  Test scanner and mover                         [P1] [x]
  - Make a folder with all file types, hidden file,
    .crdownload file and node_modules folder
  - Verify hidden / excluded files are skipped
  - Move a file twice into the same folder -> _1 name
  - Roll back and verify the original state
  Estimated time: 30 min

SPRINT 2 DONE WHEN:
  [x] Scanner returns only eligible files
  [x] Hidden, system, .crdownload and node_modules are skipped
  [x] Name clashes produce _1, _2 and never overwrite
  [x] Rollback restores every file

SPRINT 3 - ORGANIZER: MODES + PREVIEW + UNDO
Duration : Day 5-6
Goal     : Organize in 4 modes, preview first, undo any run
================================================================

TASK-015  FileOrganizer class + paths                    [P1] [x]
  - __init__(source, dest, config, recursive)
  - Without --dest, the destination is the source folder
  - PlannedMove dataclass (file + target folder)
  Estimated time: 20 min

TASK-016  get_destination_folder (4 modes)               [P1] [x]
  - type     -> <dest>/Images
  - date     -> <dest>/2026/November
  - size     -> Small (<1 MB) / Medium / Large (>100 MB)
  - combined -> <dest>/Images/2026/November
  - Unknown mode -> clear error
  Estimated time: 30 min

TASK-017  _make_plan                                     [P1] [x]
  - Scan the source, decide a folder for every file
  - Skip files already in the right folder
  - Do not re-scan a --dest folder inside the source
  Estimated time: 25 min

TASK-018  preview_organize()                             [P1] [x]
  - Total count, count + size per category
  - Destination folders for date / size / combined
  - First 10 sample moves, "... and N more"
  Estimated time: 35 min

TASK-019  organize(mode) + operation log                 [P1] [x]
  - Move every planned file (tqdm progress bar)
  - Continue after a single-file error, stop on disk full
  - Save ops_<timestamp>.json after the run
  Estimated time: 40 min

TASK-020  undo_organize()                                [P1] [x]
  - Read the newest operation log, show a summary, ask Y/N
  - Roll back, report restored count
  - Keep only failed moves in the log for a retry
  - Rename a fully undone log to .undone (next undo = older run)
  Estimated time: 40 min

TASK-021  Test organize / preview / undo                 [P1] [x]
  - Run all four modes on a test folder
  - Preview + answer N -> nothing moves
  - Organize, undo, compare folder before and after
  - Undo twice -> second undo reverses the earlier run
  Estimated time: 30 min

SPRINT 3 DONE WHEN:
  [x] All 4 modes create the right folders
  [x] Preview moves nothing and asks Y/N
  [x] Undo restores every file and removes empty folders
  [x] Running --undo with no log shows a friendly message
